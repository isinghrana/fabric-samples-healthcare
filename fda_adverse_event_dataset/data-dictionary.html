Orchestrated by pipeline pl_fda_one_time_build (Load Silver → Build Gold). One-time full load; JSON files act as Bronze, so there are no Bronze tables. All tables are Delta, unpartitioned, V-Ordered, with no array/struct/map columns (Direct Lake, SQL endpoint, Data Agent and Rayfin compatible).

Row counts are from a full load of all 92 quarter sets (21.05 M reports). Counts for tables that depend on the rule-based drug_name are set by the full build.

Source (Bronze) structure

Each file is one multiline JSON object. Lineage paths in this document are written relative to it:

{
  "meta":    { "results": { "total": … } },               ← used only for reconciliation (load_log.meta_total)
  "results": [                                          ← results[]: one element = one safety report → silver.adverse_event_report
    { safetyreportid, safetyreportversion, receivedate, receiptdate, transmissiondate, reporttype, serious, seriousness*,
      occurcountry, primarysourcecountry, primarysource{qualification, reportercountry}, sender{…}, duplicate, reportduplicate, …
      "patient": { patientonsetage, patientonsetageunit, patientsex, patientweight, patientdeath{…},
        "reaction": [ … ]                               ← results[].patient.reaction[] → silver.adverse_event_reaction
        "drug":     [ { drugcharacterization, medicinalproduct, activesubstance{activesubstancename}, …
                       "openfda": { generic_name[], brand_name[], substance_name[], rxcui[], product_type[], pharm_class_*[] } } ]
                                                        ← results[].patient.drug[] → silver.adverse_event_drug, drug_pharm_class
      } } ]
}

Not loaded (excluded on purpose): openFDA manufacturer_name, product_ndc, package_ndc, application_number, spl_id, spl_set_id, nui; drug drugauthorizationnumb, drugbatchnumb, cumulative/structured dose fields; report authoritynumb, reportduplicate.duplicatenumb, receiver.*; file meta.* (except meta.results.total for reconciliation).

Choosing among several openFDA generic names

openFDA lists the generic names of every label it matched, so 19.6% of matched drug rows have several values. Each value is normalized (step B), then: (1) use the value that matches the normalized reported active substance; (2) except when that value is just the shortest value plus extra words such as an unlisted salt (combinations with / are exempt); (3) otherwise use the shortest value, with ties broken alphabetically.

If nothing is left, the next source in step A is tried. If no source gives a name, drug_name is UNKNOWN (drug_name_source = none). UNKNOWN stays in the facts and dim_drug (is_unknown = true) but is excluded from agg_drug_summary, agg_drug_reaction, and agg_drug_reaction_signal.

Known gaps: brand names typed by reporters (HUMIRA) and misspellings stay separate; salt words not on the list (BISULFATE, TARTRATE…) still split; dose-form words without a number remain (LOSARTAN POT TAB); a strength before the name (81 MG ASPIRIN) or a drug only in parentheses (476 (MESALAZINE)) loses the name; vague class phrases (DRUG USED IN DIABETES) are kept; biosimilars stay distinct (INFLIXIMAB-DYYB); openFDA lists that mix products can pick an imperfect generic when no substance is reported; no RxNorm vocabulary is used (rxcui_all and unii_all are kept for later).

Disclaimer

About this data. FAERS adverse event reports are voluntarily submitted and are not validated. They can't establish that a drug caused a reaction, and report counts can't be used to estimate how often a reaction occurs. A report can list several drugs and several reactions, and reactions aren't linked to a specific drug. Disproportionality signals (PRR and ROR) only suggest hypotheses. Cases reported to FDA by more than one party, under different report IDs, aren't de-duplicated. Don't rely on these data to make decisions about medical care.

Drug identification. FAERS has no standardized drug identifier. Each reported drug is named by simple rules: the openFDA generic name that matches the reported active substance, otherwise the shortest openFDA generic name; if openFDA has no match, the reported active substance, otherwise the reported product name; then parenthetical text, strengths, qualifiers such as NOS, and common salt words are removed, and combination products are written as alphabetically sorted ingredients. Placeholder entries such as UNSPECIFIED INGREDIENT or UNKNOWN DRUG are grouped as UNKNOWN, which is excluded from drug-level summaries and signals. No authoritative drug vocabulary such as RxNorm is used. Misspellings, brand names entered as free text, and uncommon entries may appear as separate drugs, so drug-level counts and signals are approximate and intended for demonstration only.

Source: openFDA Drug Adverse Event bulk downloads (open.fda.gov/apis/drug/event; field definitions drugevent.yaml). See medallion-architecture-plan.md for the full design.
